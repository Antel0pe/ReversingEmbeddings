What each drawing preserves—and discards

Linear PCA: positions are actual dot products with pixel-space axes. Two axes maximize retained centered variance among linear 2D projections. The 3D view uses three axes. Neither preserves all variance; the omitted part is measured using reconstruction, including fresh joint width/lean samples.

Image-distance fit: positions are optimized so planar distances resemble original pixel-image distances. This emphasizes straight gaps between images, including shortcuts across bends. It is not a variance objective and has no reconstruction decoder here.

Sheet unfolding: positions are optimized to resemble distances travelled along a local mesh, constrained to the width/lean sheet. That lets distant parts of a fold separate, but it can change their original straight pixel distance. The mesh uses known parameter connections, not neighbors guessed from a projection.

Distance errors are relative RMS errors over all distinct displayed pairs, without rescaling. Local edge colors report map distance divided by original image distance: blue compresses, red stretches. Opposite-orientation triangles reveal local planar foldovers; they do not count every possible overlap. Source-image lookup on click retrieves stored data; it is not proof of a continuous decoder.

Why the previous distance curves bunch together

The height of a distance-from-upright plot is one scalar measurement. It can level off while neighboring images continue moving substantially along the sheet.

Four drawings, with the discarded geometry measured

Uniform width/angle sampling is not uniform surface-area sampling. The 3D projection is a view of the two-dimensional surface, not an exact isometric embedding of it. These are finite approximations of this fixed-center, fixed-height slice.
