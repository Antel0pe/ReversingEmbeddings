Can a short rule reproduce the lean field?

Each image has 784 ink-coverage values: 0 means white background; 1 means fully covered by ink. Increasing lean moves the top rightward. A lean arrow records the change of each pixel per degree, at the current width and lean.

The short boundary-aware rule uses the known stroke geometry and fits one coefficient. The polynomial fits use width and lean as inputs and learn a separate coefficient pattern for every term. This experiment tests those rules; it does not discover new knobs.

The short rule, term by term

For each pixel, add the contributions from its 16 subrows. A contribution is positive when the right edge moves into that pixel, negative when the left edge moves out, and zero when neither edge lies inside it. Width changes which pixels contain those edges.
The vertical weight is the fraction of that subrow inside the stroke. The vertical offset determines how far the subrow is from the stroke center. The cosine factor gives how quickly horizontal shear changes as the lean angle increases.
At exact edge–pixel coincidences the instantaneous derivative can have different one-sided values. This rule selects neither side there; finite differences average across the event. Small fitting and integration errors remain, including faint values outside valid coverage bounds. No proof of exact family membership or complete coordinate discovery is claimed.
