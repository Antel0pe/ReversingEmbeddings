Exactly what is retained
Indexing starts at zero: index = 28 × row + column. A coordinate value is the ink coverage at that pixel, rather than its row or column number. A large region can share one pixel value while the other 783 values distinguish the images.
The table can round values for readability. The selected-coordinate readout, copy, and JSON export use the original unrounded numbers. The 2D positions come from the earlier graph-distance unfolding; they are not two original pixel axes. This is a finite sampled sheet and does not provide a continuous inverse decoder between vertices.
