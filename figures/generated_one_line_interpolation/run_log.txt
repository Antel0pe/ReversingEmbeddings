PART 8  five lines that DO add up: warp coefficients, not pixels
  every setting is the root stroke pushed through one affine map of the
  canvas:   x = bx + sx*X + a12*Y ,  y = by + sy*Y   (no vertical shear)
  so each image is described by five warp numbers (sx, a12, sy, bx, by).

  5 lines in warp space, the dials as given  (cx, cy, height, width, lean):
    residual 7.525e-01 absolute  (3.86e+00% relative)
  5 lines in warp space, lean swapped for height*tan(lean):
    residual 3.730e-14 absolute  (5.32e-13% relative)
  -> with the right fifth dial the five warp lines add EXACTLY: the family
     is a flat 5-dimensional plane in warp space, not a curved sheet.

  cost of turning those five warp numbers back into 28x28 pixels, by
  resampling the root image: median 15.74%, p95 20.75% of the image

  control: is that 15% the five lines, or the 28x28 template?  Redo the
  identical warp on a finer root template, then area-average back to 28x28.
    root template 56x56 (pitch 0.5 px) -> median   3.74%
    root template 112x112 (pitch 0.25 px) -> median   1.70%
    root template 224x224 (pitch 0.125 px) -> median   0.27%
    root template 448x448 (pitch 0.0625 px) -> median   0.11%
  the five warp lines are unchanged throughout; only the template changes.
